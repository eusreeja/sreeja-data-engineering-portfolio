🔗 Links, Tables and Lists

In this section, we will learn how to create links, tables and lists in HTML.

Links

Links are created using the <a> tag. The href attribute specifies the URL of the page the link goes to.

Example:

NASA
Athlete Country

Explore Space

Discover the universe at NASA — live rocket launches, Mars missions and more.

Explore a live 3D view of our planet at NASA Eyes on the Earth — real satellites orbiting Earth right now.

Since the < and > characters are reserved in HTML, you need to use the &lt; and &gt; entities to display them as text. For example:

<a href="https://www.nasa.gov/">NASA</a>

Tables

Tables are created using the <table> tag. Inside a table, you can use the <tr> tag to define a table row, the <th> tag to define a table header, and the <td> tag to define a table cell.

Example:

<table>
  <tr>
    <th>Athlete</th>
    <th>Country</th>
  </tr>
</table>
